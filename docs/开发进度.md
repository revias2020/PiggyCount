## Phase 6 · 视觉与性能打磨

> 2026-08-14 grilling 锁定。双轨里程碑；**不做**换皮/暗色、预防性长列表分页；上架相关见「发布准备」。

### 原则

- 视觉：**神似** `docs/assets` fig2–6（层次/主色/卡片气质），不抠像素
- 顺序：明细 → 记一笔弹层 → 报表 → AI / 我的
- 性能：真机可感知卡顿为准；本阶段仅约定的轻量修复
- 改页时顺手收间距 Token（不单独开设计系统大重构）

### 视觉轨

- [x] 明细页对齐参考图气质（汇总卡、日分组、空态）
- [x] 记一笔弹层对齐（结构/间距/键盘区气质）
- [x] 报表页对齐（汇总/趋势/构成/对比/排行层次）
- [x] AI / 我的：气质与一致性收尾
- [x] 高频页统一 Loading / Empty / 简要错误（明细、记一笔、报表、分类、AI 配置）
- [x] 动效三处：记一笔弹层进出、FAB 按压/长按语音反馈、明细列表轻过渡
- [x] 改动页面顺手收 `PigTokens` 间距（明细 / FAB / 记一笔 / 报表 / 我的 / AI）

### 性能轨

- [x] 明细标签查询收敛（减少按笔重复查）
- [x] 月内分组/汇总移出 build 热路径（`MonthLedgerView` + `monthLedgerProvider`）
- [ ] 真机走查；若切报表周期明显卡，再单开报表聚合优化（本阶段不预做分页）

### 明确不做（本阶段）
