## 1. 产品概述

**小猪记账**是一款 Android / iOS 双端个人记账 App，界面仅中文。

核心价值：

- 手动记账足够快（底部弹层 + 自定义数字键盘）
- 智能记账够用（截图自动 / 分享入账 / 语音 / AI 对话分析）
- 报表可读（周月年自定义 + 趋势 / 构成 / 月度对比 / 单笔排行）
- 本机优先，可选 WebDAV / S3 云同步

**不做**（相对 BeeCount 主动裁剪）：多币种、账户/支付方式、预算、生物识别锁、暗色模式、微信/支付宝账单自动同步、发现页、订阅/内购、多语言、大模型 ASR。

## 4. 功能规格

### 4.1 明细

- **一体顶栏**（仅本 Tab）：`piggyCount` 图标 +「小猪记账」+ 当前账本 ▾ + 日历入口 + 搜索入口；**不**显示壳层 `AppTopBar`
- 展示**当前账本**账单，按日分组；日汇总支出/收入
- **月度汇总条**：左侧点选年月（底部弹层 **年月网格**）；右侧三列 收入｜支出｜结余（结余 = 收入 − 支出）
- **日历页**（独立页）：打开时聚焦明细当前月；与明细月互不回写；格内可同时显示 `-支出` / `+收入`；选日看当日列表；「在该日记账」预填该日；「今天」；无记一笔 FAB；列表标签位顶参考图账户位
- **账单搜索**（独立页，对齐 BeeCount）：关键词（备注/分类/金额字串/标签）+ 金额区间 + 日期区间 + 分类筛选；批量改备注 / 改分类 / 删除；当前账本
- 空态：暂无数据（**不要**「自动同步微信支付」类入口）
- 右下角扩展 FAB「记一笔」
  - 单击 → 打开记一笔弹层（图 3）
  - **长按** → Speed Dial 扇形三按钮（主色蓝气质，非黄球）
    - 以 FAB **中心**为圆心的左上真扇形；展开时主钮收成小圆锚点
    - 半透明遮罩 + 短文案：拍照 / 语音 / 图片
    - **拍照** → 相机 → Vision 确认入账
    - **语音** → 系统 ASR → AI 结构化 → 确认/落库
    - **图片** → 相册选图 → Vision 确认入账（原「我的 · 选择截图识别」迁此）
  - 交互：按住拖到目标松手执行；未选中松手则取消（**废弃**长按上滑直接语音）
- 点击账单 → 编辑（复用记一笔表单）
- 按类型筛选（支出/收入/全部）——本轮不做，可后续补

### 4.1.1 账本列表与管理

- 唯一入口：顶栏「当前账本名」
- 列表内：选中切换、新建、重命名、删除（删除需确认；至少一个账本不可删光）
- 不在「我的」重复入口

### 4.2 记一笔（手动）

底部弹层（图 3）：

1. 支出 / 收入切换；日期、时间；关闭
2. 大号金额输入（¥）
3. 分类选择：随「一级/二级」模式变化  
   - 二级：先选一级，再选二级（含「+」进入分类管理或快速新增，MVP 可只跳管理页）
4. 标签多选（可放在备注行附近或独立一行）
5. 备注输入（**无相机图标**）
6. 自定义键盘：数字、退格、+/-、「再记一笔」、「保存」
7. 落库到**当前账本**

### 4.3 报表

顶栏同壳层：`小猪记账` + 当前账本名 ▾（切换/管理账本）。对照图 4 + 图 6：

| 模块 | 说明 |
|---|---|
| 周期 | 周报 / 月报 / 年报 / 自定义 |
| 范围切换 | `< 日期 >` |
| 类型 | 支出 / 收入 切换 |
| 汇总卡 | 本期支出(或收入)、日均、环比、收支结余 |
| 趋势 | 面积/折线图 + 触点 tooltip |
| 构成 | 环形图 + 列表；维度切换：**主分类 / 子分类 / 标签** |
| 月度对比 | 近数月柱状图（「本月」高亮）；年/周下可隐藏或改为对应对比，MVP 优先月报完整实现 |
| 单笔排行 | 单笔金额排行；左侧分类图标+名称；时间；次要信息：**备注**；右侧金额 |
| 不做 | 「订阅设置」、支付方式展示 |

报表页右侧常驻 **AI 浮动球** → 进入 AI 账单助手。

### 4.4 AI 账单助手（图 5）

- 空态问候 + 能力说明
- 快捷 Chip：今日建议、周/月分析、预算与支出分析（分析语义保留，**不做预算功能**，话术改为「花费与结余分析」类）、大额支出、省钱建议、异常检测、年度回顾、最大支出类别等
- 底部输入框 + 发送；支持**语音输入**（系统 ASR 填入文本或直接送结构化）
- 可进行账单分析对话；若用户意图为记账，走与 BeeCount 类似的「提取 BillInfo → 确认/落库」流水线

### 4.5 我的

入口与开关：

| 入口 | 说明 |
|---|---|
| 云服务 | 配置 WebDAV / S3；默认同步关闭（仅本机） |
| AI 模型配置 | 默认智谱；另支持 OpenAI 兼容（Base URL / Key / Model） |
| 分类管理 | 支出/收入分套；各自一级↔二级切换；增删改排序 |
| 标签管理 | CRUD；可禁用「自动生成」时仅允许选用已有标签 |
| 数据管理 | CSV 导入 / 导出 |
| 开关：AI 智能助手 | 排在「截图自动记账」**之前**；关闭后仅隐藏报表 AI 浮动球 |
| 开关：截图自动记账 | Android 监听相册截图；iOS 快捷指令方案（照抄 BeeCount） |
| 开关：自动生成标签 | 智能记账时是否允许 AI 创建新标签 |
| 关于 | 版本号等 |

> 账本管理**不在「我的」**：见 §4.1.1，仅顶栏账本列表。  
> **不做**「我的 · 选择截图识别」：手动选图改由明细记一笔扇形「图片」。

### 4.6 智能记账渠道（简化版 BeeCount 三层）

| 渠道 | 入口 | 说明 |
|---|---|---|
| 手动 | 记一笔弹层 | 无 AI、无图 |
| 语音 | 记一笔扇形「语音」；AI 页麦克风 | 系统 ASR → 文本 → AI 结构化 |
| 拍照 | 记一笔扇形「拍照」 | 相机 → Vision → 确认/落库 |
| 图片 | 记一笔扇形「图片」 | 相册选图 → Vision → 确认/落库 |
| 截图自动 | 开关开启后系统截图 | 照抄 BeeCount：检测 → 通知 → Vision → 确认/落库；防重复 |
| 分享入账 | 系统分享图片到 App | `receive_sharing_intent` 类方案，Vision 识别 |
| 对话 | 报表 AI 浮动球（受助手开关控制） | 分析 + 可选记账 |

**去掉**：大模型 ASR / `fromAudio` 直连语音模型；若保留 BeeCount 式接口，`fromAudio` 改为「本地 ASR 文本 + fromText」。

### 5.3 AI 流水线（参考 `references/BeeCount/lib/ai/README.md`）

保持单向依赖，去掉账户相关：

```
渠道入口 → AiBookkeeper.fromText / fromImage
         → ExtractionContext（当前账本分类树 + 标签 + 开关）
         → ExtractionEngine（Prompt + Provider.chat/vision）
         → List<BillInfo>
         → BillCreationService（匹配分类/标签、可选自动建标签）
         → 落库 + 可选触发同步
```

配置存储：SharedPreferences（provider、key、model、baseUrl、是否启用等）。

### 5.4 代码规范（强制）

实现阶段必须遵守，评审时按此检查：

**结构与去冗余**

- 单一职责：Widget / Service / Repository 各管一层，禁止「复制粘贴改几个字」的平行实现
- 能复用则抽组件或函数；禁止为「看起来对称」而保留死代码、未使用参数、注释掉的大段旧代码
- 业务判断集中在 Service / Provider，UI 只负责展示与触发
- 参考 BeeCount 时**理解后重写**，不要整文件搬运再删改到面目全非

**可读与注释**

- 注释要**详细、说清为什么**：公开 API、复杂分支、手势/权限/同步/AI 解析等非显而易见逻辑必须写清意图与边界
- 文件头可用简短模块说明；类/方法对「输入、输出、副作用、失败时行为」写明白
- 禁止无意义注释（如 `// 设置颜色` 对着 `color = ...`）；禁止用注释代替删代码
- 命名用准确英文标识符；用户可见文案一律中文

**风格**

- 与 Flutter / Dart 官方 style 一致；格式化统一（`dart format`）
- UI 走 Token，避免魔法颜色/间距散落
- 异步要处理 loading / 错误；用户可感知的失败给中文提示

## 7. 云同步（S3 / WebDAV）

- 默认：**仅本机**，云同步关闭
- 「我的 → 云服务」配置其一：
  - WebDAV：地址、用户名、密码、远端路径
  - S3：endpoint、region、accessKey、secretKey、bucket、SSL/端口等（对齐 BeeCount 表单项）
- 行为参考 BeeCount：序列化账本数据 → 指纹比对 → 上传/下载合并
- MVP 策略建议：
  - 以「整账本快照 + syncId 合并」起步，避免一上来做细粒度 CRDT
  - 冲突：提示用户「保留本地 / 使用云端」或「按更新时间合并」（实现阶段选定一种写清）

## 8. 截图 / 分享（照抄 BeeCount 要点）

### 8.1 Android 截图自动记账

- 需相册/媒体权限；监听截图目录或 MediaStore 新增
- 防抖 +「已处理路径」持久化，避免重复入账
- 通知进度：检测到截图 → 识别中 → 成功/失败
- 识别依赖 AI Vision；未配置 AI 时明确提示去配置
- 注意：Android 10+ 分区存储下**无法删除系统截图**，文案需提示用户自行清理（BeeCount 已有说明可复用改写）

### 8.2 iOS

- 使用快捷指令 / App Intents 触发「截图 → 打开 App 识别」（BeeCount：iOS 16+）
- 「我的」内提供设置引导页

### 8.3 分享入账

- 注册为图片分享目标；冷/热启动都能吃到共享图片
- 进入识别确认流（与截图共用 Vision 管道）

### 8.4 与「记一笔」边界

记一笔**永远不出现**选图/相机；图片只走自动截图与分享渠道。

## 9. 语音记账

1. 申请麦克风权限；调用系统 SpeechRecognizer / SFSpeech
2. 得到文本后调用 `AiBookkeeper.fromText`
3. 展示识别结果卡片（金额/分类/备注/标签）供用户确认保存  
   （是否静默直存：MVP 建议**先确认再存**，降低误记）

手势：明细页「记一笔」**长按 → Speed Dial**（拖到拍照/语音/图片松手；注意与单击冲突）。

## 13. 验收标准（MVP）

1. 三 Tab 可用；明细为一体顶栏（品牌+账本+日历+搜索）；报表/我的为壳层顶栏；账本列表可切换并完成新建/重命名/删除；切换后明细/报表数据隔离；「我的」无账本管理入口  
2. 记一笔可连续「再记一笔」；数据出现在明细与报表  
3. 支出/收入分类可分别切一级/二级，记一笔 UI 正确响应  
4. 报表含图 6 主要模块，构成图可切到「标签」  
5. AI 配置智谱或 OpenAI 兼容后：对话分析可用；分享一张支付截图可识别出金额  
6. 开启截图自动记账后，支付页截图能走通知识别流（真机）  
7. 长按记一笔扇形：拍照 / 语音 / 图片均可走通确认流  
8. CSV 导出再导入不丢关键字段  
9. WebDAV 或 S3 配置后可完成一次上传/下载（至少单向成功）  
10. 全中文；无暗色；无账户/预算/多币种入口  
11. 「我的」无「选择截图识别」；AI 助手开关仅控制报表 AI 球

## 14. 风险与注意

| 风险 | 应对 |
|---|---|
| Android 截图监听机型差异 | 照抄 BeeCount 等待文件可读 + 失败文案；真机多测 |
| iOS 截图不能像 Android 静默监听 | 快捷指令方案 + 引导页 |
| Vision/Chat 费用与 Key | 用户自备 Key；本地只存配置 |
| 同步冲突 | MVP 明确单一策略，避免静默丢数据 |
| 手势 Speed Dial 与单击冲突 | 长按阈值后再展开；未选中松手取消；单击仍开记一笔 |
