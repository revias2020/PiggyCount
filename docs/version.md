# 小猪记账 · 升级日志

## 0.2.1

**版本：** `0.2.1+3`  
**相对：** `0.2.0+2`  
**日期：** 2026-08-20

### 截图自动：稳定期（ADR-045）

Android 检测到截图后先进入约 **2s** 稳定期（自最近一次 MediaStore 变更起算）；系统预览里编辑/覆盖会重置计时，期满且文件仍在才识别入账。稳定期结束前不记「已处理」，避免裁剪后的同路径覆盖被跳过。预览里删除则取消本次。连拍按路径独立计时。分享入账不受影响。

### 程序日志：稳定期可见 + 条数上限

- 稳定期关键节点（开始等待 / 变动重置 / 删除取消 / 静止入账）经原生桥接到程序日志，tag 为 `Screenshot`，可在「关于 → 程序日志」查看与导出
- 程序日志条数上限 **1000 → 2000**（仍约 48 小时裁剪）

### 报表统计：排除墓碑（ADR-046）

报表 / 小组件 / AI 摘要的合计与构成此前未过滤 `deletedAt`，会把已删账单算进去，导致比明细偏大、构成笔数与下钻列表不一致。现与明细一致：只计存活账单。删除确认补充「删除后不可恢复」（单删 / 批量）。

### AI 分类消歧（ADR-047）

Prompt 分类列表改为按主类分组，嵌入主类裸名与「主类-子类」；说明先定主类、再选子类、都不贴则用主类。落库与确认弹层优先解析复合名，仍接受裸名；明细等展示逻辑不变（仍显示分类裸名）。

### 小组件：小号本月金额紧凑展示

小号「收支速览」底栏本月支出 / 收入过长易截断；改为紧凑格式：`<1k` 为 `¥`+整数，`[1k,1w)` 为 `¥x.xxk`，`≥1w` 为 `¥x.xxw`（档内截断两位）。今日支出仍完整两位小数。

### 版本与文档

- `pubspec.yaml` → `0.2.1+3`
- `CONTEXT.md` / `docs/development.md` / `docs/framework.md`：截图稳定期（ADR-045）；用户可见统计（ADR-046）；AI 分类消歧（ADR-047）；小号本月紧凑金额

### 不受影响

本机 schema、账单身份 / 指纹规则、分享入账路径未变。

## 0.2.0

**版本：** `0.2.0+2`  
**相对：** `0.1.0+1`  
**日期：** 2026-08-20

### AI 提取：账单时间消歧

截图 / 订单页常同时出现多个时间（如瑞幸：自取时间靠上、订单时间靠下）。旧 prompt 只写「优先支付时间」，遇到无「支付」字样的订单详情时，模型容易误取自取、配送等履约时间。

本版约定：

- **账单时间** = 资金变动完成时刻
- 优先级：支付 / 交易成功 / 付款 → 订单 / 下单 / 成交
- **禁止**当作账单时间：自取、配送、预约、预计送达、取餐等
- 若只有履约类时间 → 使用提取时刻
- 文本 / 语音 / 图片共用同一规则

账单指纹仍按「时间到秒」计算；提错时间会换指纹，本机若已有同额同时则无法再记。已入账的跨设备身份不随改时间而变。

### 同步：账单身份与指纹分离

跨设备认亲改为创建时 UUID（账单身份）；账本 + 金额到分 + 时间到秒只作指纹，用于本机去重和同步预览里的疑似重复。

- 改金额 / 时间不再裂成两条
- 两台各记一笔同额同时：预览可选 **保留** 或 **合并**（合并留下较晚改动，另一条墓碑）
- 账单墓碑超过 90 天：写云前裁掉，本机同步时硬删
- 工作区 JSON `version` → 2（账单带 `syncId`）；CSV 仍不带身份（导入即新身份）

### 后台直存：重复账单通知文案

截图自动 / 分享入账落库时，若命中指纹冲突（已存在相同账本、金额与时间的账单）：

- 通知栏标题：**记账取消**（不再用「识别失败」）
- 点失败通知后的 Dialog 标题：同步为 **记账取消**

其它失败路径标题不变。

### 分享入账：热启动不再闪启动页

Android 系统分享经透明 `ShareRelayActivity` 转发后再进入主界面。App 仍在前台时分享入账，不再闪一下品牌启动页。

### 桌面小组件

**进入体验：** 点小组件经 `WidgetRelayActivity` 中转；冷启动、热启动都不展示启动页（冷启可接受短暂浅色等待）。桌面图标冷启仍为蓝底白猪。

**眼睛隐藏：** 切换后就地重渲，避免金额先闪再变成 `****`。

**样式：**

- 小号：底栏「本月支出 / 本月收入」标签缩小一号
- 中号：近 7 日柱图贴底、固定高度，不再随槽位把剩余空间撑满

### 版本与文档

- `pubspec.yaml` → `0.2.0+2`（关于页经 `package_info_plus` 自动显示）
- `docs/framework.md`、`docs/development.md`：账单身份 / 指纹 / 折合 / 墓碑裁剪；小组件布局与启动路径

### 不受影响

本机 schema 仍为 v9（`syncId` 列已存在，无需迁移）。分类 / 标签规则未变。工作区文件升级为 version 2。
