# 小猪记账 · 框架说明

> 产品地图：边界、信息架构、功能模块、工程骨架。  
> 实现细节（怎么跑、文件路径、拍板细则）见 [development.md](./development.md)。  
> 用户安装见 [README.md](../README.md)。

**一句话：** 本机优先的个人记账 App；可选自备网盘做多端工作区同步；可选自配 AI 做智能记账。无广告、无强制账号。

两份文档共用同一套**功能维度**（见下表）。本文件讲「有什么 / 边界在哪」；development 讲「怎么实现」。

| 维度 | 本文件 | development |
|---|---|---|
| A 工程底座 | 技术栈、目录、数据模型 | 启动、库、迁移、品牌资源 |
| B 核心数据 | 账本 / 分类 / 标签 / 账单要点 | 规则、管理交互、播种 |
| C 日常记账 | 明细 · 记一笔 · 日历 · 搜索 | UI 路径、弹层、账单行 |
| D 报表分析 | 周期与三卡 | 再显刷新、下钻、排行 |
| E 智能记账 | 渠道总览 | 服务商、提取引擎、前台/后台 |
| F 数据互通 | 同步 vs CSV | 云配置、工作区合并、导入向导 |
| G 桌面扩展 | 收支速览摘要 | 布局、热区、深链 |
| H 系统与发布 | 平台差异、视觉纪律 | 日志、验收、风险 |

## 1. 产品边界

### 1.1 做什么

| 维度 | 能力 |
|---|---|
| **B 核心数据** | 多账本；支出/收入两层分类；标签组（字符串 / 数值） |
| **C 日常记账** | 手动记一笔；日历；搜索与批量；统一账单行 |
| **D 报表** | 周/月/年/自定义；趋势、构成、对比、单笔排行 |
| **E 智能（可选）** | 语音 ASR / 拍照·图片 Vision；Android 截图自动与分享入账；CSV AI 映射 |
| **F 数据互通** | 本机 CSV；分类包；自备 WebDAV/S3 **工作区合并**（不是 CSV 当同步） |
| **G 桌面** | Android 收支速览小组件（小/中）；深链 `piggycount://` |

### 1.2 刻意不做

多币种、账户/支付方式、预算、暗色、多语言、内购、家庭协同、微信/支付宝官方账单拉取、iOS 小组件（0.1.0）、**换皮**（换主色板或另立视觉语言；与「视觉打磨」不同）。（大模型语音入账已纳入 ADR-052，不再列非目标。）

### 1.3 视觉纪律

- **视觉打磨**：在既定蓝主色 `#2F6BFF` + 参考图气质下补层次与反馈。  
- **换皮**：换主色 / 上暗色 / 另立语言 → 不做。  
- 分类/标签管理避免「系统设置 ListTile 堆」的**管理页感**。

## 2. 信息架构

底栏三 Tab：**明细 | 报表 | 我的**。

```
明细（日常记账主场）
├── 一体顶栏：品牌 · 账本 ▾ · 日历 · 同步 · 搜索
├── 月度汇总（年月网格 + 收入/支出/结余）
├── 按日账单列表
└── FAB：单击手动记一笔；长按扇形（拍照 / 语音 / 图片）

报表（分析主场）
├── 壳层顶栏（账本）
├── 周期条 + 支出/收入
└── 汇总 / 趋势 / 构成 / 对比排行

我的（配置与目录）
├── AI 设置 · 云服务 · 同步 · 数据管理
├── 分类 / 标签 · 桌面小组件（Android）
├── 开关：截图自动 / 自动生成标签
└── 关于（使用教程 · 程序日志）
```

账本 CRUD **只在**顶栏账本列表，不在「我的」重复。

## 3. 功能维度 B · 核心数据

| 概念 | 要点 |
|---|---|
| **账本** | 账单容器；分类/标签**全局**不按账本隔离；未删除名唯一；删本可能因对端较晚记账而**复活** |
| **分类** | 支出/收入两套树；主/子深度 2；**同收支内**名唯一（跨类型可同名）；可自定义图标（仅绑当前分类，**不同步进同步**） |
| **标签** | 属于一个组；字符串组可多选，数值组按 `[min,max)` 互斥；全库标签名/组名唯一；组内有标则禁删组；允许空组 |
| **账单** | 金额、类型、分类、标签、备注、账单时间；跨设备身份 = **账单身份**（创建时 UUID）；**账单指纹**（账本 UUID + 金额到分 + 时间到秒）只用于去重，不是身份（ADR-044） |
| **目录维护** | 「清除未使用」删无引用项；「恢复默认」按出厂清单补缺；启动**不会**自动补回用户删除 |

播种：仅在**新库创建**时导入出厂分类/标签。

## 4. 功能维度 C · 日常记账

| 子功能 | 用户感知 |
|---|---|
| **明细** | 按月浏览当前账本；一体顶栏；不做支出/收入类型筛选 |
| **记一笔** | 工作台弹层 + 金额键盘；时间用自定义 Dialog（双输入 + 快捷格，ADR-051）；主类可直记或展开子类；标签走次级弹层；备注另层调系统键盘 |
| **扇形** | 长按 FAB → 拍照 / 语音 / 图片（智能入口收口，非附图） |
| **日历** | 独立页；与明细月互不回写；「在该日记账」预填选中日 |
| **搜索** | 当前账本；关键词含标签名；可批量改备注/分类/删除 |
| **账单行** | 分类圆标 + 标签 chip 横滑 + 时间/备注 + 金额；仅明细长按删 |

弹层分档：工作台（记一笔 85%、分类编辑 50%、标签/组 40%）vs 次级（备注 ~36%、选标 ~55% 等）。记一笔主层不随系统键盘上移。

## 5. 功能维度 D · 报表分析

- 周期：周 / 月 / 年（网格弹层）/ 自定义（系统区间）。  
- 三卡：趋势（面积折线）→ 构成（环用**观赏色板**，列表用真实分类图标）→ 对比排行（柱 + Top10 → 排行全页）。  
- **再显刷新**：账单变更只标过期；用户再次面对报表时重算（不做明细式全程 watch）。
- 构成列表可下钻到分类/标签明细（带入当前报表周期，只读）。
- **用户可见统计**：合计 / 构成 / 排行只计存活账单；墓碑不入账（与明细一致，ADR-046）。

## 6. 功能维度 E · 智能记账

### 6.1 配置

内置智谱（不可删）+ ≤5 自定义 OpenAI 兼容。能力绑定三项：**文本对话**、**图片理解**、**语音直接记账**（各需该侧测通成功；语音模型可空=该商不支持）。Key 只存本机。语音识别引擎见 ADR-052（系统 ASR / 可下载离线 / AI 直接记账）。

### 6.2 提取约定

应付与实付并存 → 取**实付**；备注 ≤15 字，优先店名/商品；支付方式走标签。  
**账单时间** = 资金变动时刻（支付 / 交易成功 / 订单时间等）；自取、配送、预约、预计送达等履约时间不当作账单时间；仅有履约时间则用提取时刻。  
**分类（ADR-047）：** Prompt 按主类分组，嵌入裸名与「主类-子类」；先主类再子类，都不贴用主类。落库兼容复合名与裸名；UI 展示始终裸名。

### 6.3 渠道（两套落库语义）

| 类型 | 渠道 | 落库 |
|---|---|---|
| 前台确认 | 扇形拍照/图片、备注旁相机 | Vision → 识别确认弹层；相册可**系统多选**（上限 9），确认层**按图分组**（ADR-058） |
| 前台确认 | 语音 | 按引擎：听写→结构化 或 AI 直接记账 → **单卡确认**（ADR-052）；能力未就绪仅弹层内「去设置」（ADR-057） |
| 后台直存 | 截图自动、分享入账 | 通知进度 → **FGS 保活**（ADR-054）→ Vision → **自动落库**（截图自动：稳定期 3s + 关联窗 15s，进度可早于落库，见 ADR-048）；结果按账单笔数分桶（ADR-056）；分享先 FGS 再回来源，直存中返回不拆引擎；Android 支持单张/`SEND_MULTIPLE` 多选（ADR-058） |

分享入账**不受**「截图自动」开关约束。报表对话助手（「AI 智能助手」）已下线，见 ADR-049。

## 7. 功能维度 F · 数据互通

拆成三件事，勿混名：

| 入口 | 职责 |
|---|---|
| **云服务** | 只配连接（关 / WebDAV / S3）+ 测连 → **已测通** |
| **同步** | 多设备**工作区合并**（`piggy_workspace.json`）；确认 → 预览 → 写入 |
| **数据管理** | 本机 CSV 导入/导出；与同步无关 |

同步次序：分类/标签对齐 → 账本同名折合 → 账单按身份合并。同指纹不同身份在预览里可选折合。冲突取**较晚改动**（墙上时钟）。一次对齐**全部账本**。自定义图标不同步。S3 为简化 HTTP（非 SigV4），真机优先 WebDAV。

CSV：需表头；可选 AI 映射（列名→分类→标签）；映射「自动 / 忽略」。未知账本名会新建账本。分类包另走分类管理导入导出（可含自定义图标 zip）。

## 8. 功能维度 G · 桌面扩展

仅 Android **收支速览**：

- **小**：今日支出主视觉 + 本月收支；整卡记支出。  
- **中**：今日支出|收入 +「+」记支出 + 近 7 日柱（贴底、固定高度，不随槽位撑满）；今日文案→明细；柱→报表近 7 日。**不是**左右半卡分别记收入/支出。  
- 刷新：保存 / 回前台 / ~30 分 / 每日 0:00。深链 `piggycount://`；关 Flutter 默认深链防崩溃。

## 9. 功能维度 A · 工程骨架

### 9.1 技术栈

| 层 | 选型 |
|---|---|
| 框架 | Flutter、Riverpod |
| 本地库 | Drift / SQLite（`sqlite3_flutter_libs`） |
| 图表 | fl_chart |
| 网络 | `http`（WebDAV / 简化 S3、OpenAI 兼容） |
| 其它 | `speech_to_text`、`home_widget`、`app_links`、本地通知 |
| 包名 | Android `com.xiaozhu.piggy_count`；iOS `com.xiaozhu.piggyCount` |

### 9.2 目录

```
lib/
  main.dart / app.dart     # 启动、深链/分享
  styles/                  # Token（仅亮色）
  data/                    # 表、库、种子、repositories
  sync/                    # 工作区合并
  ai/                      # 提取引擎、客户端、服务商
  providers/ pages/ services/ widgets/
  widget/                  # 桌面渲图（Android）
android/ ios/ test/ tool/ docs/
```

独立重写，勿整文件搬运参考项目。

### 9.3 数据模型（逻辑）

| 表 | 要点 |
|---|---|
| Ledgers | `syncId`、软删、`updatedAt` |
| Categories | `kind`、`parentId`、图标、`syncId` |
| TagGroups / Tags | 组类型与 scope；标签色与区间 |
| Transactions | `syncId` 身份、`fingerprint` 去重、`happenedAt`、`source`、软删 |
| TransactionTags | 多对多 |
| AppSettings | 开关等键值 |

Schema 版本与迁移见 development。

### 9.4 UI 共性

- 品牌：桌面/关于 `app_icon`；启动必须 `splash_icon`（勿直接用桌面图做 Android 12+ 圆裁）。  
- 分类彩标（icon key）；标签色入库；构成环观赏色 ≠ 列表彩标。  
- Token：`lib/styles/tokens.dart`。

### 9.5 平台（0.1.0）

| | Android | iOS |
|---|---|---|
| 真机目标 | **主路径** | 能编过即可 |
| 小组件 / 截图自动 | 有 / MediaStore | 无 / 快捷指令引导 |
