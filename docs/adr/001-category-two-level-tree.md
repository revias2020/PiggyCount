# ADR-001：分类为固定两层树（主 / 子），无全局一级/二级模式开关

- 状态：Accepted（grilling 2026-08-14）
- 背景：曾误做成「仅扁平单层」；产品实际需要主分类下可挂子分类，且管理交互对齐参考图弹层。

## 决策

1. 分类深度固定为 2：主分类（`parentId == null`）与子分类（`parentId` → 主分类）。
2. 取消「记账时一级模式 / 二级模式」全局设置；记一笔固定为：点主分类展开子类，**主分类也可直接记账**。
3. 分类管理主网格只列主分类；点击打开详情弹层：编辑 / 改为子类 / 删除 + 子分类列表（添加、点子类出菜单）。
4. 「改为子类」：目标主分类下已有子分类时拒绝，提示「该分类下存在子分类，无法调整」。
5. 子分类菜单：编辑｜改为主分类｜移至其他主分类｜删除。

## 补充（grilling 续）

6. 删除规则：
   - **子分类**：有账单引用则禁删，提示有账单。
   - **主分类**：若自身有账单 → 禁删并提示；若某子分类有账单 → 禁删并列出那些子分类名；否则级联删除主分类 + 全部子分类。
7. 报表构成维度：**主分类｜子分类｜标签**。
8. 「改为子类 / 移至其他主分类」选父：弹层网格，未选灰显、选中恢复彩色，确认后生效。

## 后果

- 恢复 `parentId` 两层树业务；管理页主网格 + 详情弹层 + 子类菜单；记一笔主类展开子类且主类可直记。
- 撤销「仅扁平单层」方向；报表恢复主/子/标签构成。
- 种子：常见主分类列表；子分类可空。
