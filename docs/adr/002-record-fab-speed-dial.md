# ADR-002：记一笔长按扇形菜单 + AI 助手开关归位

- 状态：Accepted（grilling 2026-08-15）
- 背景：智能入口分散（「我的」选截图识别、记一笔长按上滑语音）；参考图为中央「+」上扇形三按钮。需收拢入口并与现有右下角「记一笔」FAB 适配。

## 决策

1. **废弃**「记一笔长按上滑 → 语音」。改为：**长按记一笔 → Speed Dial 扇形三按钮**（拍照 / 语音 / 图片）。
2. 交互为 **按住拖选**：手指拖到某一项松手执行；松手时未落在任一项则取消（菜单收起、无动作）。
3. 三项行为：
   - **拍照**：调系统相机 → 同一套 Vision 识别确认流（`source` 记为 camera）
   - **语音**：原语音记账确认流（系统 ASR → 结构化）
   - **图片**：相册选图 → 原「选择截图识别」同一套 Vision 流（`source` 可用 screenshot / gallery）
4. 「我的」**删除**「选择截图识别」入口；手动选图改由明细长按「图片」。
5. 「AI 智能助手」开关移到「我的」第三块（智能相关）：排在 **「截图自动记账」之前**；**仅控制报表页 AI 浮动球显隐**，不影响记一笔长按三项。
6. 视觉：扇形绕右下角记一笔 **向上/向左**展开；配色跟主色蓝/软底，**不跟参考图黄球**；布局气质参考扇形，不抠像素。

## 补充（grilling 2026-08-16 · 扇形美观）

7. **真扇形**：以 FAB **中心**为圆心（非右下角），半径约 96–110，三钮落在左上约 100° / 135° / 170°；钮与锚点净距 ≥ 16，钮间距清晰。
8. 展开时主「记一笔」宽胶囊 **收成小圆锚点**（标准 Speed Dial），避免宽条被圆钮压住。
9. 展开时：**半透明遮罩**压暗列表 + 三钮下短文案（拍照 / 语音 / 图片）。

## 后果

- `RecordFab` 手势从「长按上滑」改为 Speed Dial；语音入口改为扇形「语音」。
- 相册/相机入账入口集中到明细；「我的」只保留自动截图监听开关（及 iOS 引导等）。
- AI 助手开关与模型配置分区：开关与截图自动同组，模型配置仍可在云服务/模型区。
- 布局以极坐标扇形 + 收锚 + 遮罩文案为准，修正早期相对右下角的挤叠偏移。
