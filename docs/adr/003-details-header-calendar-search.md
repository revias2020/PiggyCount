# ADR-003：明细一体顶栏 + 日历页 + 账单搜索

- 状态：Accepted（grilling 2026-08-16 Round 1）
- 背景：明细开头要对齐 BeeCount 明细信息架构（布局/功能，不抄配色）。旧约定是三 Tab 共用「小猪记账 + 账本名」顶栏，明细内另有左右切月汇总卡；无日历、无搜索。

## 决策

1. **明细一体顶栏（方案 C）**：明细 Tab 自带顶区（品牌 + 账本 ▾ + 日历 + 搜索），**隐藏**该 Tab 上的壳层 `AppTopBar`。报表 / 我的仍用共用顶栏。
2. **月度汇总条**：点选年月（非箭头为主）；展示收入｜支出｜结余。
3. **日历**：独立「日历页」（月摘要格子 + 当日列表 + 在该日记账 + 今天），非弹层。
4. **账单搜索**：独立页，能力对齐 BeeCount（关键词 + 金额/日期/分类筛选 + 批量改备注/改分类/删除）；当前账本范围。
5. **视觉**：沿用小猪记账亮色蓝主色与既有 Token；不复制 BeeCount 黄底或红/绿金额配色习惯到品牌层（金额正负色仍可用项目既有收入/支出色）。

## 补充（grilling Round 2）

6. 明细顶栏品牌：`piggyCount` 图标 +「小猪记账」。
7. 日历格：支出/收入可同时显示（项目收支色，非抄参考图红绿）。
8. 日历月与明细月**独立**；从日历返回不改明细月份。
9. 搜索关键词额外匹配标签名。
10. 列表右侧原「账户」位改为展示标签。
11. 「在该日记账」预填选中日（无选中则今天）。

## 补充（grilling Round 3）

12. 进入日历时默认聚焦**明细当前月**；返回仍不回写明细月。
13. 本轮不做明细「全部/支出/收入」类型筛选。
14. 日历页不放记一笔 FAB；入账仅「在该日记账」。
15. 年月点选 UI：底部弹层 + **年月网格**（非滚轮、非系统 DatePicker）。

## 后果

- `HomeShell` 需按 Tab 条件显隐 `AppTopBar`（或明细自绘 SafeArea 顶区）。
- 账本切换入口在明细顶栏与报表/我的顶栏两处并存，但都打开同一账本列表。
- 开发文档 §顶栏/§4.1 中「三 Tab 统一顶栏、明细仅月份汇总卡」的表述需随实现修订。
- 新增日历页、搜索页及对应查询/批量能力。
- 日历与明细各维护自己的月份状态，避免隐式耦合。
