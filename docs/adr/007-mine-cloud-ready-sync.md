# ADR-007：「我的」分区重排 + 已测通门槛 + 快捷同步

- 状态：Accepted（grilling 2026-08-16）
- 背景：云服务上传/下载埋在「我的 → 云服务 → 长表单底部」，已配好的人每次同步都要挖配置。连接测试已存在，但原先**不落盘、不当门槛**，与「别一键点到必失败」冲突。同时「我的」把 AI 模型与云服务、分类与数据管理混在同一视觉块，扫描成本高。

## 决策

1. **「我的」块顺序**：AI 模型配置（单独）→ 云服务 + 数据管理（同卡、无组标题）→ 分类管理 + 标签管理 → 智能开关 → 关于。数据管理副标题为「本地 CSV 文件导入导出」，与云端区分。
2. **云服务页（方案 1）**：仅当**已保存 + 字段齐 + 已测通**且当前表单指纹未变时，顶栏展示「下载并导入 / 上传当前账本」，连接配置收进 `ExpansionTile`（默认收起）。否则整页填表 +「测试连接」，不展示上传/下载。
3. **快捷同步（方案 2）**：已测通时在「我的 · 云服务」下露出双按钮条；下载确认与云服务页相同，上传不额外确认。本轮不展示「上次同步时间」。
4. **已测通**：连接指纹（同步方式 + 连接字段）曾被证明可用——来源为连接测试成功，或上传/下载成功。改指纹则失效。保存配置**不必**先测；测连**不**隐式保存整份表单（可只记指纹，保存时若指纹一致则保留标记）。
5. **字段齐**：WebDAV 至少 URL；S3 至少 endpoint、bucket、access、secret。
6. **否决**：用「备份与同步」作产品总名；行尾图标-only 同步；以实时双向同步替代 CSV 快照；保存时强制先测连。

## 后果

- 修正 ADR-002 后果中「模型配置仍可在云服务/模型区」：模型配置单独成块，与云服务分离。
- `CloudSyncConfig` 增加 `verifiedFingerprint` 与就绪判定；「连接测试」词条允许写入已测通标记，仍不等于替用户点保存。
- 日常同步路径缩短为「我的 → 点按钮」或「云服务 → 页顶按钮」；配置仍集中在云服务页。
