# ADR-005：报表用「再显刷新」，不用明细同款全程监听

- 状态：Accepted（grilling 2026-08-16）
- 背景：明细经 Drift watch 随账单变更即更新；报表曾是一次性快照，账单变更后易过期。报表聚合比列表贵，且 Tab 用 IndexedStack 保活，若每笔写入都重算会在用户看着明细时后台打满。

## 决策

1. 采用 **报表再显刷新**：账单变更只标报表过期；在用户再次面对报表时重算（切到报表 Tab、从编辑/AI 等回到报表、或报表 Tab 已可见时变更完成）。
2. **全部**账单写路径都会让报表过期（记一笔、删除、搜索批量、AI、CSV 等）。
3. 刷新时 **静默替换** 旧快照；不要求下拉刷新；不采用与明细相同的全程 watch。

## 后果

- 报表与明细的新鲜度策略刻意不同；后人不应「顺手」把报表改成持续 watch 除非产品改口。
- 漏标过期的写路径会再次表现为「改了账单报表不更新」。
